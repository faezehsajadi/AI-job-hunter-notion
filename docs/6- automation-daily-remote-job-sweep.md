# Notion Automation (Optional) — Job Matches → Follow‑ups

Start with **one** automation. Add more only if you need them.

---

## 1) Create a follow‑up task when you apply (recommended)

**Trigger (in `Job Matches — Daily`):**  
When `Status` changes to **Applied**

**Action (create a page in `Tasks`):**
- **Task** → `Follow up: {Title} — {Company}`
- **Due** → Today (or Today + 1 day)
- **Status** → `To do`
- **Next action** → your default next step
- *(Optional)* Link it back to the job match (relation)

**Why this helps:** Applied jobs automatically become actionable tasks.

---

## 2) Scheduled “Daily Remote Job Sweep” task (optional)

**Trigger (in `Tasks`):**  
Scheduled (daily/weekly)

**Action:**  
Create a task named `Daily Remote Job Sweep` with your preferred default properties.

**Why this helps:** Guarantees the routine exists even if you forget to create it.

---

## 3) Duplicate prevention (optional but recommended)

Pick one rule:
- Only create a follow‑up task if the job match has **no related task** yet, **or**
- Use a consistent naming rule and manually delete duplicates if they happen

---

That’s it. Keep it simple: set sensible defaults (Due, Next action), then adjust over time.
